# F13LD.mesh — instructions for Claude

## Commits and pull requests
- Do not add session links (e.g. `Claude-Session: https://claude.ai/...`) to commit messages, pull request descriptions or any file in this repo.
- `Co-Authored-By: Claude …` trailers are fine.

## Code layout
- Numbered classic scripts share one global scope and load in numeric order (see README → Project structure). Top-level code that runs at load time may only use things defined in the same or a lower-numbered file.
- Worker code lives in `worker/`. Bump `F13LD_MESH_VERSION` in `01-config.js` and the header label in `index.html` on every release.
- Serve over http(s) to test; `file://` does not work.

- v0.14.0 preview rebuild P2 (scene shader, `docs/P2_SCENE_SHADER_SCOPE.md`, decisions in its §0): every visible part is a member of one scene. `16-preview-scene.js` builds it from the app state and the raymarcher pulls it on every dirty frame (`rm._sceneProvider = previewSceneSync`); a signature (`previewSceneSig`) skips unchanged frames, so **any new setting the preview reads must be added to `previewSceneSig`**. `previewSceneChanged()` forces a rebuild; `triggerPreview(q)` = quality + shape grids + resolve once settled. `rm.setScene(desc)` packs the std140 block `Scene` (layout comment above `_buildShader` in `20-raymarcher.js`; members, groups, sources, counts) and three atlases (`_atlasFor`: tiles R8 with a 1-voxel wrapped border, regions R16F, part shapes R16F). Two program variants: `single` (one drawn part, constant indices) and `multi`. Keep the number of call sites of the scene function small (normals and marching go through one call in a loop): drivers inline every call, and with many call sites SwiftShader lost the context. Sources are exactly the P1 single-part bakes per member (`sceneSourceNeed`); aperiodic regions keep the P1 box because the selected part's raw bake sets `recipe._previewFieldMin/Max`, which the export reads — that is what keeps exports byte-identical. The weld union preview bake is gone (export only, `14-weld-bake.js`); legacy raymarcher setters (`setGhosts`, `setJoins`, `setAssemblyMode`, `setSolidMode`, `useField`, `setBaseColor`) no longer affect drawing. Weak-GPU fallback: GPU frame time from `EXT_disjoint_timer_query_webgl2` (frame gap without it), sampled only while the view moves (`rm._frameSample`, `SLOW_FRAME_MS` 70); ~1.5 s of slow frames with two or more lattices arms it (`PSC.slowGpu`), then parts not being edited are shells only while the view moves (their sources stay in the scene so atlases don't change); the "Simplified while moving" pill turns it off; off under automation. Weld editor greys out Anchor / Graded unless the weld has a solid and a lattice part. `setQuality` never restarts a compile already running for that quality. Weld colour: `weldGroups[gid].colorHex`, `setWeldColor`, `resolveBodyColor` returns the weld colour for members. Debug: `F13LD_scene.state()`, `rm.debugSceneDistances(ptsMm)`, `?debug=1` overlay.
